## Features

- Current temperature
- Feels-like temperature
- Humidity
- Wind speed
- Coordinate validation

Run the application:

```bash
python main.py
```

## Project structure

- `main.py` — CLI entry point
- `weather_api.py` — API requests
- `validation.py` — coordinate validation


## CLI

The application asks the user for latitude and longitude.
